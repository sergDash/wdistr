Пакет `github-cli` (команда `gh`) входит в базовый набор wdistr —
в дистрибутиве он доступен из extra, собирать ничего не нужно.

## Первый запуск авторизации

```sh
gh auth login
```

Диалог последовательно предлагает выбрать:

1. **Where do you use GitHub?** — GitHub.com.
2. **Preferred protocol** — HTTPS (по умолчанию).
3. **How would you like to authenticate?** — Login with a web browser.
4. CLI печатает восьмизначный код и просит открыть ссылку
   `https://github.com/login/device` — вводишь код там, подтверждаешь
   доступ.

После подтверждения в браузере CLI отвечает `Congratulations! You are
authenticated` — токен записан в системное хранилище ключей (keyring),
ручных файлов править не нужно. Проверка:

```sh
gh auth status
```

## Что подтверждено на рабочей машине

Авторизация выполнена 2026-10-19: аккаунт `sergDash`, протокол HTTPS,
токен в keyring, области `gist`, `read:org`, `repo`, `workflow` — gh
готов к созданию релизов и работе с репозиторием.

## Релизы через gh

После авторизации релиз создаётся из консоли: annotated-тег + команда
`gh release create` с заметками (sha256, дата, ссылка на MEGA). Тег
сам по себе релизом не является — на GitHub это разные сущности: тег
живёт в git, релиз создаётся поверх него и показывается на странице
Releases.
