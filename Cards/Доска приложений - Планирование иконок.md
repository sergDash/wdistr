## Источник иконок — Papirus

Папирус — тема иконок по умолчанию дистрибутива (`papirus-icon-theme`
в `packages[]`). Берём из неё:

- **scalable SVG** (`/usr/share/icons/Papirus/scalable/apps/*.svg`) —
  предпочтительный формат: вектор, масштабируется без потери качества
  под любой размер клетки доски;
- если для программы нет SVG в scalable, берём растр
  `128x128/apps/*.png` или следующий доступный размер.

## Подписи

Под каждой иконкой — подписываемое имя программы (колонка «подпись»
в `icons.tsv` скрипта). Длинные двухсловные названия переносятся на
две строки через `\n`: File Roller, Android Studio, Beekeeper Studio,
LM Studio, Amnezia VPN. Подпись WhatSie (не WhatsApp — это клиент
WhatsApp, не сам мессенджер). Остальные — одна строка.

## Пути поиска

1. распарсить `.desktop`-файл (`/usr/share/applications/`,
   `/var/lib/flatpak/exports/share/applications/`) — поле `Icon=`;
2. если значение — имя без пути, искать файл `<имя>.svg` (затем `.png`)
   в Papirus;
3. если в Papirus нет — искать в `/usr/share/icons/hicolor/`
   (туда AUR-пакеты кладут свои иконки);
4. если и там нет — брать путь напрямую из `Icon=`, если это абсолютный
   путь (так делают некоторые Electron-приложения).

Плоские экспорты flatpak (dash-core) отдают иконки из
`/var/lib/flatpak/exports/share/icons/hicolor/` — источник `flatpak`
в таблице.

## Композиция — ImageMagick

ImageMagick уже в составе (`imagemagick` в `packages[]`) и на рабочей
машине. Из него:

- **montage** — сборка сетки: `montage *.png -tile 11x6 -geometry 128x128+16+16 -background black applications.png`;
- **convert/magick** — подготовка: ресайз SVG в PNG нужного размера
  (`magick -density 192 icon.svg -resize 128x128 icon.png`), подгонка
  под единую сетку (все иконки в квадрат 128×128 с прозрачными
  полями — у Papirus уже так).

Порядок файлов в montage задаёт порядок на доске — перемешать список
случайно (`shuf`) перед сборкой, чтобы иконки стояли не по категориям.

Если SVG не рендерится штатным делегатом ImageMagick (depends от
сборки), фоллбэк — `rsvg-convert` из пакета `librsvg` (в системе стоит
как зависимость GTK): `rsvg-convert -w 128 icon.svg -o icon.png`.

## Размеры и размещение

Рабочие параметры (уточняются при первой сборке):

- клетка: 128×128, отступ 16 px — итоговый размер иконки на доске ~128 px;
- сетка под 63 иконки: 11×6 или 12×6 (последний ряд неполный —
  3 пустые клетки, montage заполняет слева направо);
- итоговое изображение: ~1800×1100 px при 11×6 (с отступами);
- фон: чёрный `#000000` (или чуть смягчённый `#111111` — решить
  по виду).

Размещение готового файла: `applications.png` в корне репозитория,
в `README.md` — после скриншота установленной системы (решение
2026-10-23). В дистрибутив (ISO) доска не поставляется — это материал
репозитория, не системы.

## Порядок работ

Скрипт сборки: `tools/build-applications-board.sh`. Запуск с рабочей
машины (где стоят Papirus и hicolor-иконки установленных программ):

```bash
bash tools/build-applications-board.sh          # → applications.png в корне
bash tools/build-applications-board.sh путь.png # → указанный файл
```

Скрипт сам: ищет иконки по таблице (Papirus → hicolor), ресайзит
в 128×128 через rsvg-convert/magick, перемешивает порядок (shuf),
собирает montage сеткой 11×6 на чёрном фоне. Зависимости: imagemagick,
librsvg, papirus-icon-theme — всё уже в составе дистрибутива.

При добавлении новой GUI-программы в дистрибутив: добавить строку
в таблицу иконок выше и в `icons.tsv` внутри скрипта (дублирование
осознанное — карточка читается глазами, скрипт исполняется).
