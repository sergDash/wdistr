## Механизм

Единственный источник — `mirrors.txt` в корне репозитория (голые URL
построчно, строки с `#` — комментарии, в список не идут — опыт
2026-10-13: без фильтра комментарий превращался в битую строку
`Server`). Из него `python3 install/regen-custom-commands.py`
генерирует:

1. `mirrorlist` — файл вида `Server = <url>` для pacman;
2. ключ `mirror_regions` в конфиге archinstall;
3. команды доставки обоих в живую и установленную систему (плюс хук
   `wdistr-mirrors.hook`, восстанавливающий список при обновлениях
   pacman-mirrorlist).

## Ключевое требование: имя региона должно совпадать

В `mirrorlist` перед серверами стоит строка-регион `## wdistr`, а в
конфиге archinstall — ключ `mirror_regions: {"wdistr": [...]}`.
**Это одно и то же имя, и менять его можно только синхронно в обоих
местах.** Почему:

- парсер зеркал archinstall (`_parse_local_mirrors`) считает регионом
  любую строку после `## ` и группирует под ней `Server = ...`;
  строки до первого заголовка уходят в регион `Local`;
- `get_status_by_region(name)` из конфига делает `mappings[name]` —
  если такого заголовка в файле нет, падение по **KeyError**;
  опыт 2026-10-08: вообще без заголовка сервера уходили в `Local`
  и установка вставала.

Поэтому «просто вписать свой комментарий вместо региона» нельзя.
Что МОЖНО: обычный комментарий от строки `#` (одинарный) — парсер
его не трогает, он не похож ни на `## `, ни на `Server = `. Так
в шапке mirrorlist описывается назначение списка:

```
# Наш статический список хороших серверов: состав закрыт,
# правится только файлом mirrors.txt в репозитории.
## wdistr
Server = ...
```

Имя региона исторически было `## Russia`; заменено на `## wdistr`
2026-10-14 (решение пользователя: страна ни при чём — это наш
закрытый список).

## Сопутствующие решения и ловушки

- archinstall запускается с `--offline`: без него он берёт зеркала с
  archlinux.org/mirrors/status по имени региона, игнорируя URL из
  конфига (случай 2026-10-08: archlinux.gay из глобального списка
  сорвал pacstrap).
- Состав mirrors.txt закрыт (AGENTS.md): удаления/добавления — только
  по явному решению; причин удаления пишем комментарием прямо в файле.
- Перед закачкой `setup-continue` проверяет зеркала поимённо
  (`[доступно]` / `[НЕ доступно]` с причиной) — по этому выводу
  анализируют, кого вычистить из списка.
- Состав серверов и порядок (приоритет) — в самом `mirrors.txt`.
