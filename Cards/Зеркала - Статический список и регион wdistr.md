## Механизм

Единственный источник — `mirrors.txt` в корне репозитория (голые URL
построчно, строки с `#` — комментарии, в список не идут — опыт
2026-10-13: без фильтра комментарий превращался в битую строку
`Server`). Из него `python3 install/regen-custom-commands.py`
генерирует:

1. `mirrorlist` — файл вида `Server = <url>` для pacman;
2. ключ `mirror_regions` в конфиге archinstall;
3. доставку: в живую среду — хук `wdistr-mirrors.hook` и источник
   `/usr/local/share/wdistr/mirrorlist` (нужны при сборке: там
   pacman-mirrorlist свежеустанавливается и затирает список);
   в целевую — только одноразовую запись `/etc/pacman.d/mirrorlist`
   при установке, без хука (решение 2026-10-15, см. ниже).

## Ключевое требование: имя региона должно совпадать

В `mirrorlist` перед серверами стоит строка-регион `## wdistr`, а в
конфиге archinstall — ключ `mirror_regions: {"wdistr": [...]}`.
**Это одно и то же имя, и менять его можно только синхронно в обоих
местах.** Почему:

- парсер зеркал archinstall (`_parse_local_mirrors`) считает регионом
  любую строку после `## ` и группирует под ней `Server = ...`;
  строки до первого заголовка уходят в регион `Local`;
- `get_status_by_region(name)` из конфига делает `mappings[name]` —
  если такого заголовка в файле нет, падение по **KeyError**;
  опыт 2026-10-08: вообще без заголовка сервера уходили в `Local`
  и установка вставала.

Поэтому «просто вписать свой комментарий вместо региона» нельзя.
Что МОЖНО: обычный комментарий от строки `#` (одинарный) — парсер
его не трогает, он не похож ни на `## `, ни на `Server = `. Так
в шапке mirrorlist описывается назначение списка:

```
# Наш статический список хороших серверов: состав закрыт,
# правится только файлом mirrors.txt в репозитории.
## wdistr
Server = ...
```

Имя региона исторически было `## Russia`; заменено на `## wdistr`
2026-10-14 (решение пользователя: страна ни при чём — это наш
закрытый список).

## Сопутствующие решения и ловушки

- archinstall запускается с `--offline`: без него он берёт зеркала с
  archlinux.org/mirrors/status по имени региона, игнорируя URL из
  конфига (случай 2026-10-08: archlinux.gay из глобального списка
  сорвал pacstrap).
- Зеркала в работающей системе правятся обычной правкой
  `/etc/pacman.d/mirrorlist` (решение 2026-10-15, прежний запрет
  отменён): файл входит в backup-массив pacman-mirrorlist — правки
  переживают обновления пакета (новый сток приходит в `.pacnew`).
  Поэтому хук-восстановитель и кормушка
  `/usr/local/share/wdistr/mirrorlist` в целевую больше не
  доставляются — они перебивали бы пользовательские правки; в живой
  среде остались (там хук нужен при сборке).
- Состав выбирается по статистике `rate-mirrors.py` (решение
  2026-10-15): ноль отказов в истории, сортировка по средней
  скорости, одна позиция на страну. **Черные списки отменены** тем же
  решением: причина прыганий была в приоритете IPv6 над IPv4
  (gai.conf, опыт 2026-10-15), а не в зеркалах — банов больше не
  будет, выбор только по свежему замеру. Yandex возвращён в пул
  кандидатов явным решением 2026-10-15 (в `mirrors.txt` пока не
  входит — состав меняется отдельным решением). Смена состава:
  прогон скрипта → переписываем mirrors.txt, обоснование —
  комментарием прямо в файле.
- Перед закачкой `setup-continue` проверяет зеркала поимённо
  (`[доступно]` / `[НЕ доступно]` с причиной). Если не ответило **ни
  одно** зеркало — установка останавливается до archinstall с кодом 1
  (решение 2026-10-15: `--offline` отключает самопроверку сети
  archinstall, без остановки pacstrap завис бы на мёртвых зеркалах).
  Проба — 3 круга с паузой 3 с: однократная давала ложное «всё
  мертво» на кратковременной просадке (опыт 2026-10-15). Если ответило
  хоть одно — установка идёт с **полным** списком, без отсеивания.
- URL-ы из ключа `mirror_regions` конфига при `--offline` в закачке не
  участвуют: archinstall собирает Server-строки из локального
  mirrorlist **по имени региона** (`regions_config`, archinstall 4.5),
  а сами адреса из конфига не читает. Поэтому отсеивание их в конфиг
  (было в setup-continue до 2026-10-15) на список качания не влияло —
  мёртвый код; фактический список всегда брался из mirrorlist-файла.
  Полный список к тому же самовосстанавливается: ожившее посреди
  установки зеркало pacman берёт на следующем файле.
- Состав серверов и порядок (приоритет) — в самом `mirrors.txt`;
  история замеров — в `mirrors.db` рядом со скриптом `rate-mirrors.py`.
- **Перед прогоном rate-mirrors VPN должен быть выключен** (правило
  2026-10-16): замер через туннель искажает статистику — зеркала
  выглядят медленными или отказывают ложно, и в отбор попадает не то
  (на целевой системе VPN не будет — замер должен отражать эти
  условия). Агент перед прогоном напоминает и ждёт подтверждения.
  Отсюда же — очистка отметок failures от 2026-10-16: прежние отказы
  частично были замерами через VPN, таблица обнулена, новый этап
  статистики без VPN.
