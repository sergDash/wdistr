Проверяем строки таблицы в `Cards/Базовый набор программ.md` итерациями
по три. На каждую строку — три проверки: источник, наличие в конфиге,
содержательное примечание.

## Шаг 1. Источник (репозиторий)

Для пакетов из репозиториев:

```bash
for p in firefox mousepad file-roller; do
  pacman -Si $p | grep -E "^Репозиторий|^Описание"
done
```

В колонку `Источник` — название репозитория (`extra`, `core`,
`multilib`); для AUR и flatpak — `AUR` / `flatpak` как есть. Слово
«родная» не использовать (решение 2026-10-16). `Описание` из pacman —
сырьё для примечания, но на английском: своё, короткое, по-русски.

Для AUR — RPC API (по запросу на пакет, `results` пуст = не найден):

```bash
for p in librepcb beekeeper-studio; do
  curl -s "https://aur.archlinux.org/rpc/v5/info?arg[]=$p" |
    python3 -c "
import json,sys
r=json.load(sys.stdin)['results']
if r: d=r[0]; print(f\"{d['Name']}: AUR, версия {d['Version']} — {d['Description'][:85]}\")
else: print('в AUR не найден')"
done
# librepcb: AUR, версия 2.0.1-1 — A free EDA software to develop...
# beekeeper-studio: AUR, версия 1:6.1.2-1 — Modern and easy to use SQL client...
```

Для flatpak — flathub API или `flatpak remote-info flathub <app-id>`.

## Шаг 2. Наличие в конфиге

Пакет из репозитория должен быть в `packages[]`:

```bash
python3 -c "
import json
c=json.load(open('install/archinstall-config.json'))
p=c.get('packages',[])
for x in ['firefox','mousepad']:
    print(f'{x:17}', 'в packages[]' if x in p else 'НЕТ В КОНФИГЕ!')"
```

AUR-пакеты — в `AUR_PACKAGES` первого запуска, flatpak — в
`FLATPAK_APPS` (обе в `install/files/first-boot.sh`):

```bash
grep -A16 "^AUR_PACKAGES=" install/files/first-boot.sh | grep -E "protonup-qt|portproton"
grep -A5  "^FLATPAK_APPS="  install/files/first-boot.sh | grep steam
```

Если пакета в конфиге нет — строка в таблице ложная (так уже терялись
zeal и семь приложений): либо добавить пакет и прогнать
`python3 install/regen-custom-commands.py`, либо признать строку
устаревшей.

## Шаг 3. Примечание

Вместо «уже в конфиге», «добавлен 2026-10-11», «перешёл из flatpak» —
короткое назначение программы через двоеточие или запятую, чтобы её
знали те, кто не помнит названия:

```
| gimp | extra | конфиг | растровая графика: ретушь, фотообработка |
| steam | flatpak | скрипт | игровые клиенты; свои runtime-драйверы, без вопросов vulkan |
```

Историю (когда вносился, откуда перешёл) смотреть в git, в таблице она
не нужна. Целевые причины оставлять: почему выбран flatpak, а не AUR
(steam, whatsie); отсылки к компаньонам (`qt6-multimedia-ffmpeg` →
okular); служебные пометки («в AUR-списке первым» — для amnezia).
