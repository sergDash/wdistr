# wdistr

Свой дистрибутив на базе Arch Linux: переупаковка стока и докрутка под
философию «поставил и работает» — минимум настройки, минимум вопросов при
установке, оболочка fish. Своего репозитория пакетов нет: база —
стандартный Arch, всё доведённое живёт в профиле ISO и конфиге
установщика.

Всё для сборки — в этом репозитории: профиль ISO (`iso/`), конфиг
установщика и доставка настроек (`install/`), скрипты виртуальных машин
(`vm/`), перенос настроек с хоста (`settings/`). Знания — в `Cards/`
(рабочие карточки, на них ссылается книга) и `handbook/` (книга о
проекте, пока черновики). Работа ведётся через агента (opencode):
пользователь принимает решения, агент выполняет работу.

## Инструкция

Сказать агенту - давай пройдемся по проекту и соберем свой дистрибутив.

Дальше процесс выглядит так:

1. **Агент подготовит всё сам**: скачает стоковый ISO Arch с проверкой
   чек-суммы, создаст и запустит виртуальную машину.
2. **В окне VM после загрузки живой среды выполни руками команду
   `archinstall`** и пройди критичные пункты — без них система выйдет
   нерабочей:

   1. Mirrors and repositories → Select regions → **Russia**. Back.
   2. Disk Configuration → Partitioning → **Use a best-effort default
      layout** → **ext4** → **No** (home). Back.
   3. Authentication → User account → Add a user → **user / 123** →
      **Yes** (sudo). Confirm and exit. Back.
   4. Profile → Type → **Server** → **sshd**. Back.
   5. Network configuration → **Use Network Manager**. Back.
   6. **Install** → Yes.
   7. **Reboot**.

3. **Перезагрузка**: если установочный диск не вытащен, VM снова
   стартует с ISO — в меню загрузки выбрать третий пункт **Boot existing
   OS** (загрузка в установленную систему) и войти `user / 123`.
4. **Скажи агенту, что система установлена и готова к дальнейшим
   шагам** — он подключится по SSH и сделает остальное: обновление,
   пакеты для сборки, ключи, проверки. После этого можно собирать ISO.

Готовый ISO записывается на флешку и запускается в железной машине.
В живой среде — две команды:

```sh
disks                                  # список дисков: какой диск есть и чем занят
setup ivan 12345 /dev/sda              # всё установит (имя, пароль, диск)
```

Перезагрузка — система работает.

Разбор нештатных ситуаций и детали — в `Cards/Сборочная виртуальная
машина.md`; принятые решения проекта — в `AGENTS.md`.
