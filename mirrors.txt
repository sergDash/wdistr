# Зеркала wdistr: состав выбирается по статистике, запретов нет.
# Инструмент: python3 rate-mirrors.py (в корне репозитория) — обходит
# официальный статус, меряет скорость и отказы из нашей сети, хранит
# историю в mirrors.db. Отбор: ноль отказов в базе, сортировка по
# средней скорости, одна позиция на страну (географическое
# разнообразие); не более трёх позиций одного оператора — фаланга
# cicku.me (9 стран) при полном включении завязала бы список на одну
# сеть.
# Черные списки отменены (решение 2026-10-15): причина прыганий была
# в приоритете IPv6 над IPv4 (строка precedence в gai.conf), а не в
# зеркалах — банов больше не будет, выбор только по свежему замеру.
# Yandex возвращён в пул кандидатов (2026-10-15).
# Остаются только https: http-варианты редиректят на https и отнимают
# секунды на каждую попытку (замер 2026-10-13).
# far.fi из нашей сети не отвечает (замер 2026-10-14) — это факт
# измерения, не запрет: при изменении сети проверяется заново.
