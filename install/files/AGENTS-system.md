# AGENTS.md — wdistr (установленная система)

Инструкция для агента opencode, запущенного В УСТАНОВЛЕННОЙ системе.
Рядом с этим файлом — логи первого запуска (`first-boot.log`); та же
копия лежит в `/usr/local/share/wdistr/AGENTS.md`.

## Что это за система

wdistr — свой дистрибутив на базе Arch Linux: переупаковка стока под
философию «поставил и работает» — минимум настройки, минимум вопросов;
оболочка fish, рабочий стол Cinnamon, файловая система btrfs с
мгновенными снапшотами (timeshift), шифрования дисков нет. В конфиге
установки 102 пакета, из AUR — 13 разрешённых (android-studio и др.),
4 flatpak. Своего репозитория пакетов нет.

Исходники, состав (Cards/Базовый набор программ), книга и принятые
решения проекта: github.com/sergDash/wdistr — в установленную систему
они не поставляются, решения принимаются там.

## Как устанавливалась (двухфазная схема, решение 2026-10-14)

1. `setup <имя> <пароль> <диск>` — фаза 1, офлайн: разметка своими
   руками (parted, mkfs, сабволюмы `@` и `@home`). Разметка отобрана
   у archinstall: единый проход означал бы, что повтор после обрыва
   сети стирает диск вместе с кэшем скачанных пакетов.
2. `setup-continue <имя> <пароль> <диск>` — фаза 2, сеть: archinstall
   в режиме `pre_mounted_config` на смонтированных разделах — закачка
   пакетов и настройка целевой. Оборвалась сеть — повторяется ТОЛЬКО
   эта команда: диск не переразмечается, кэш `pacstrap`
   (`/var/cache/pacman/pkg` на целевом) цел, докачивается недостающее.
3. Доставка из живой среды копированием (бинарник opencode, шрифты
   Windows, курсоры McMojave, тема, карты keyd, vconsole+терминус) и
   custom_commands archinstall (зеркала, темы dconf/GTK/Mozilla,
   таймеры, юниты, udev-правила serial).
4. Первый запуск — фоновый `wdistr-first-boot`: pacman -Syu (все
   базы, включая multilib), flathub + 4 flatpak, yay + 13 AUR-пакетов
   (по одному, упавший не срывает остальных), очистка кэшей после
   успеха.

## Логи

- `~/install-log/first-boot.log` — шаги первого запуска: строка
  `+ команда` и её `rc=`; в конце «инициализация завершена» либо
  «с ОШИБКАМИ (таймер повторит через час; перезагрузка не нужна)».
- `~/Desktop/Установка-завершена.txt` — маркер успеха (ставится только
  при чистом проходе).
- Ожидаемые НЕПОЛАДКИ, не баги:
  - `rc!=0` у `wdistr-timeshift-check` — до настройки timeshift-gtk
    нет конфига, таймер крутится формально (норма);
  - `port-routing.service` failed в виртуальной машине — юнит
    привязан к сети реальной машины, безвреден.
- **Если инициализация завершилась со сбоями — перезагрузка НЕ
  обязательна.** Таймер `wdistr-first-boot-retry.timer` сам повторяет
  установку через час после завершения юнита со сбоем (час считается
  от момента падения; шаги идемпотентны, `--needed` пропускает уже
  стоящее и добирает только упавшее, маркер встанет после успеха).
  Нетерпеливым: `systemctl restart --no-block wdistr-first-boot` —
  повтор сразу (флаг `--no-block` обязателен, без него команда
  заблокирует терминал до завершения многочасового юнита).

## Самопроверка (сказали «проверь» — выполняй по шагам)

1. `tail -50 ~/install-log/first-boot.log` — итог «инициализация
   завершена», без строк «с ОШИБКАМИ».
2. Маркер `~/Desktop/Установка-завершена.txt` на месте.
3. `systemctl list-timers wdistr-` — три таймера обновления
   (sys/aur/flatpak) заведены и активны.
4. `pacman -Q fish cinnamon android-tools zig terminus-font` —
   базовый состав стоит; `ls /usr/local/bin/opencode` — бинарник.
5. `grep -c Server /etc/pacman.d/mirrorlist` и его содержимое —
   только наши зеркала (список закрыт).
6. `ls /etc/udev/rules.d/01-wdistr-serial.rules` — serial-доступ
   к платам (Arduino) на месте.
7. `df -h /` — свободного места достаточно (кэши должны были
   очиститься после успеха).

## Чего не делать

- Не менять `/etc/pacman.d/mirrorlist` и не добавлять зеркала —
  список закрыт проектом, правится только в mirrors.txt в репозитории.
- Не чистить кэши pacman/yay, пока first-boot не завершился — таймер
  повтора добирает упавшие пакеты как раз из кэша.
- Не пересобирать системные пакеты «для улучшений» — значительная
  часть состава заморожена решением проекта.
