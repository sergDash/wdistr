# Базовый набор программ

Рабочий список состава дистрибутива. Источники проверены 2026-09-26:
локальной базой extra зеркала, базой multilib и API AUR.
Решения о включении — за пользователем; после решения позиции переносятся
в `archinstall-config.json` (пакеты pacman) или сюда же со статусом.

## В конфиге установщика (уже ставится с ISO)

- Рабочий стол: `xorg-server`, группа `xfce4`, `lightdm`, `lightdm-gtk-greeter`
- Оболочка и ввод: `fish`, `keyd`, `nano`
- Композитор и интеграция: `picom`, `virtualbox-guest-utils`
- Звук: `pipewire`, `pipewire-pulse`, `pipewire-alsa`, `wireplumber`,
  `xfce4-pulseaudio-plugin`, `pavucontrol`
- Сеть и шрифты: `network-manager-applet`, `ttf-dejavu`
- База «поставил и работает»: `firefox`, `mousepad`, `file-roller`, `flatpak`

## Проверено установкой в тестовой VM (2026-09-26), в конфиг пока не перенесены

Список ещё не финальный (решение пользователя отложено).

- Из extra: `neovim`, `godot`, `thunderbird`, `zeal`, `deltachat-desktop`,
  `signal-desktop`, `ghostty`, `keepassxc`, `obsidian`, `syncthing`,

## Кандидаты: где брать

- `steam` — **только multilib** (в extra нет); без включения репо multilib
  в pacman.conf не установится
- `vscodium` (это codium) — AUR `vscodium`; есть также flatpak
- `session` — AUR `session-desktop` (варианты `-bin`, `-appimage`)
- `pragtical` — AUR `pragtical` / `pragtical-bin`
- `whatsie` — только AUR `whatsie-git` (в extra и flatpak не найден)
- AmneziaVPN — AUR `amneziavpn-bin` (клиент) или `amnezia-box` (платформа)

## Открытые вопросы

- Допустим ли AUR в дистрибутиве вообще; если да — какой менеджер
  (paru/yay ставятся только из AUR сами)
- Включать ли multilib (для steam; это стандартный репозиторий Arch)
- VirtualBox в госте: `virtualbox` есть в extra и ставится, но в тестовой VM
  вложенная виртуализация не включена — внутри гостя VBox будет работать
  с ограничениями; на обычном железе ограничений нет
