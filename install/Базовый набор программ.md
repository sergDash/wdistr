# Базовый набор программ

Рабочий список состава дистрибутива. Источники проверены 2026-09-26:
локальной базой extra зеркала, базой multilib и API AUR.
Решения о включении — за пользователем; после решения позиции переносятся
в `archinstall-config.json` (пакеты pacman) или сюда же со статусом.

## В конфиге установщика (уже ставится с ISO)

- Рабочий стол: `xorg-server`, группа `xfce4`, `lightdm`, `lightdm-gtk-greeter`
- Оболочка и ввод: `fish`, `keyd`, `nano`
- Композитор и интеграция: `picom`, `virtualbox-guest-utils`, `virtualbox`
  (для реальной машины; в тестовой VM вложенная виртуализация не включена)
- Звук: `pipewire`, `pipewire-pulse`, `pipewire-alsa`, `wireplumber`,
  `xfce4-pulseaudio-plugin`, `pavucontrol`
- Сеть и шрифты: `network-manager-applet`, `ttf-dejavu`
- База «поставил и работает»: `firefox`, `mousepad`, `file-roller`, `flatpak`

## Источники кандидатов (проверено 2026-09-26)

- `steam` — **только multilib** (в extra нет). multilib включить решено;
  steam добавить в `packages` после реализации (задача этапа профиля —
  правка pacman.conf живой среды и установленной системы).
- AUR — **разрешён для выбранного списка, с автообновлением** (решение
  2026-09-26). Разрешённые пакеты:
  - `vscodium` (это codium)
  - `session-desktop` (варианты `-bin`, `-appimage`)
  - `pragtical` / `pragtical-bin`
  - `whatsie-git` (в extra не найден)
  - `amneziavpn-bin` (клиент AmneziaVPN)
  Реализация (помощник AUR + автообновление) — отдельная задача: помощник
  (paru/yay) ставится из AUR же, при установке из ISO — настраивать в профиле.

## opencode — собственной сборки (решение 2026-09-26)

Не пакет `opencode` 2.0.18 из extra, а собрать самому, с патчами.
База для сборки — вопрос открыт: локальный исходник `~/src/opencode`
(git describe: v1.18.32, четыре файла с правками в working tree) против
пакета 2.0.18 из extra. Сборка — задача этапа профиля (PKGBUILD → makepkg →
pacman -U).
