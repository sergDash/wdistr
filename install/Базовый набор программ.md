# Базовый набор программ

Рабочий список состава дистрибутива. Источники проверены по базе extra
зеркала и API AUR. Решения о включении — за пользователем; всё согласованное
переносится в `install/archinstall-config.json`.

## steam — через flatpak (решение 2026-09-26)

Почему не pacman: установка `steam` из multilib интерактивно спрашивает
32-битный vulkan-драйвер под конкретное железо (`lib32-vulkan-radeon` для AMD,
`lib32-vulkan-intel` для Intel, свой для NVIDIA) — это ровно тот вопрос,
который мы хотим убрать. Flatpak-версия steam приносит свой runtime
с mesa-драйверами и ставится без единого вопроса. Multilib в дистрибутиве
остаётся (wine, 32-битные мелочи), а сам steam — flatpak-путём после
подключения flathub (задача автоинициализации первого запуска).

## Разведка источников 2026-09-27 (по выбору пользователя)

- Родные, добавлены в конфиг: `blender`, `gimp`, `inkscape`, `audacious`,
  `openrgb`, `flatseal`, `authenticator`, `discord`, `element-desktop`
  (discord и element нашлись в extra — flatpak для них не нужен).
- flatpak-программы (иерархия: родной > flatpak > AUR; ставятся после
  подключения flathub, состав утверждается отдельно): `steam`,
  `protonup-qt`, `portproton`, `librepcb`, `jan`, `localsend` — все пять
  уже работают на хосте пользователя как flatpak (проверены в деле).
- AUR — только если родного И flatpak нет: `vscodium`, `session-desktop`,
  `pragtical`, `whatsie-git`, `amneziavpn-bin`; перед включением каждого —
  проверить flathub (при реализации).
- flatpak по выбору пользователя: `steam` (решено ранее: свои runtime-драйверы,
  без вопросов выбора vulkan). Discord/Element/LocalSend изначально
  предлагались flatpak'ом, но принцип «родный > flatpak» (решение 2026-09-27)
  и данные разведки перенесли discord/element в родные; localsend — AUR-очередь.
- Читки новостей — не нужны (FeedDeck, FeedFlow, Newsflash, RSS Guard, Feeds).
