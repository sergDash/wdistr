# Чек-лист - Комфортный рабочий стол

Путеводный лист: что не хватает дистрибутиву и wdesktop, чтобы рабочий стол
был комфортным. Замечания устраняем постепенно; по этому же листу — финальная
проверка. Каждый пункт — с признаком проверки.

Статус листа: 2026-09-30.

## Дистрибутив — состав пакетов

- [x] `udisks2` и `xdg-utils` внесены в `install/archinstall-config.json`
  (2026-09-30). Проверка: `pacman -Q udisks2 xdg-utils` после установки.
- [x] Состав пополнен: `imagemagick`, `syncthing`, `gnome-keyring`
  (нужен программе Authenticator, 2026-10-08). `nm-tray` НЕ добавлялся —
  это Qt-дублёр `network-manager-applet` (nm-applet), в трее была бы
  вторая иконка сети; оставлен nm-applet. Проверка:
  `pacman -Q imagemagick syncthing gnome-keyring` после установки.
- [x] Тема иконок: **Papirus** по умолчанию — решение 2026-09-30
  (щелкали темами на сборочной: Adwaita/breeze — отвергнуты, выбор между
  elementary и Papirus — в пользу Papirus). Пакет `papirus-icon-theme`
  внесён в конфиг ЯВНО, чтобы не зависеть от зависимостей xfce4 и пережить
  уход XFCE, когда появится wdesktop (elementary из явного списка убран —
  он останется зависимостью xfce4-settings, пока XFCE стоит).
  Механика дефолта: системный `/etc/gtk-3.0/settings.ini` (исходник
  `install/files/gtk3-settings.ini`, доставляется regen-скриптом —
  решение 2026-09-30, реализовано). Файл читается GTK3 всеми
  пользователями, включая root; пользовательский
  `~/.config/gtk-3.0/settings.ini` его перекрывает. В XFCE перебивание
  xfsettingsd закрыто 2026-10-08 глобальным дефолтом
  `/etc/xdg/xfce4/xfconf/xfce-perchannel-xml/xsettings.xml` (тема,
  иконки, курсор); после ухода XFCE единственный источник —
  `gtk-3.0/settings.ini`.
  Проверка: в чистой установке GTK-программы (и от root) — Papirus
  и Adwaita-dark без ручной настройки.
- [x] Оформление GTK: `Adwaita-dark` — устраивает (замер 2026-09-30:
  `/Net/ThemeName = Adwaita-dark` на сборочной). Прописано тем же
  системным `/etc/gtk-3.0/settings.ini` (`gtk-theme-name=Adwaita-dark`),
  что и иконки — оба значения в одном файле.
  Проверка: после входа тема Adwaita-dark без ручной настройки.
- [ ] Рамки окон (xfwm4): сейчас `Default`; тема `Adwaita-dark` для xfwm4
  есть в системе — сделать и рамки тёмными? Решение за пользователем.
  Проверка: рамки и заголовки окон тёмные.
- [x] Курсор: **McMojave-cursors** вместо adwaita-cursors — решение и
  реализация 2026-10-08: `install/files/mcMojave-cursors.tar` (3,2 МБ,
  собран из `~/src/McMojave-cursors`) доставляется custom_commands в
  `/usr/share/icons/McMojave-cursors`. Назначен ОБОИМИ путями: системный
  `/usr/share/icons/default/index.theme` (`Inherits=McMojave-cursors`)
  и сессия xfce (глобальный `xsettings.xml` → `Gtk/CursorThemeName`),
  плюс `gtk-cursor-theme-name` в `gtk3-settings.ini`. Пакет
  `adwaita-cursors` в конфиге остаётся как фолбэк.
  Проверка: курсор McMojave после входа в чистой установке.

## wdesktop — задачи проекта (в его репозитории)

- [ ] `wmenu` — меню программ («Пуск»): сканирование `.desktop`,
  запуск приложений. Проверка: приложение запускается из меню.
- [ ] `wmenu`: иконки для меню. Данные: имя иконки — ключ `Icon=` из
  `.desktop` (`/usr/share/applications/`); резолв — поиск по активной
  теме иконок (каскад: `~/.icons` → `$XDG_DATA_DIRS/icons` →
  `hicolor`-фолбэк по `Inherits` из `index.theme`). Активная тема после
  ухода xfsettingsd — из системного `/etc/gtk-3.0/settings.ini`
  (`gtk-icon-theme-name=Papirus`); GTK3-бэкенд (GtkIconTheme) не обязателен,
  но свой ридер `index.theme` — это работа, варианты взвесить при
  реализации wmenu. Проверка: иконки программ в меню видны и совпадают
  с темой.
- [ ] Трей: EggTray — первый шаг, но для иконок НАШЕГО состава обязателен
  StatusNotifier (D-Bus): nm-applet зависит от `libappindicator-gtk3`,
  flameshot и discord — тоже SNI (проверено 2026-09-30).
  Проверка: иконки сети, flameshot, discord видны в трее панели.
- [ ] `wpanel`: два трея (по плану в AGENTS.md wdesktop).
  Проверка: оба трея видны, иконки кликабельны.

## Сквозная проверка (когда всё устранено)

1. Собрать ISO, поставить в чистую тестовую VM.
2. Первый вход: курсор и графика (уже закрыто — проверить, что не
   сломалось), лог first-boot в `~/install-log/`.
3. Диски: fstab поднял диск бэкапа; флешка монтируется через udisks2.
4. Перенос настроек: `settings/setup.sh` — firefox и thunderbird как дома.
5. Сессия wdesktop: вход, панель, меню, трей, автозапуск (picom, nm-applet).
6. Иконки: в меню и панели видны у всех приложений.
