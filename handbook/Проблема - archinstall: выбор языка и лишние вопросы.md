# Проблема - archinstall: выбор языка и лишние вопросы

Статус: **решено обходом** (2026-09-25). Полное решение не требуется —
проблема обходится правильными ответами при установке.

## Что случилось

Установка Arch через archinstall в госте VirtualBox, 2026-09-25:

- **Выбор языка ломает интерфейс.** Language → Russian — и вместо меню
  появляется транслитерация со знаками вопросов, пользоваться невозможно.
  Выход: Ctrl+Q (выход из archinstall) и перезапуск, язык не менять.
- **Бессмысленные вопросы.** NTP спрашивает, использовать ли сетевое
  время, а часовой пояс при этом отдельно — логично было бы вывести часовой
  пояс из NTP или наоборот, но это не решается ответом пользователя.
- **Спорный swap по умолчанию.** archinstall по умолчанию ставит swap
  «on zram» с алгоритмом zstd — для 128 ГБ оперативки это не рекомендуют
  (zram нужен для экономии памяти на слабых машинах).

## Что пробовали

- Язык: Ctrl+Q и перезапуск archinstall, оставить English — работает.
- Swap: оставили как есть для тестовой установки; наше решение — см.
  «Archinstall - Ответы для нашей системы».

## Идеи (не проверены)

- Для релизного ISO archinstall гонять из преднастроенного конфига —
  тогда большинство этих вопросов не задаётся вовсе.
