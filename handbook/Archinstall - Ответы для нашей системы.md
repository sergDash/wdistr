# Archinstall - Ответы для нашей системы

Эталон ответов при установке Arch через archinstall для тестовой сборочной
VM (2026-09-25). Цель — повторяемая установка без лишних вопросов; из этих
ответов впоследствии собирается преднастроенный конфиг.

## Ответы

- **Язык интерфейса** — не менять (English). Русский ломает интерфейс
  archinstall, см. «Проблема - archinstall: выбор языка и лишние вопросы».
- **Локаль** — `kb_layout: ru`, `sys_lang: ru_RU.UTF-8`, `sys_enc: UTF-8`,
  консольный шрифт `Cyr_a8x16` (по извлечённому конфигу).
- **Регион зеркал** — Russia.
- **Разбивка диска** — best-effort default, файловая система ext4, без
  отдельного `/home`, без шифрования (шифрование — «на улучшения»).
  Итог: два раздела — 1 ГБ fat32 `/boot`, остальное ext4 `/`.
- **Swap** — archinstall поставил «on zram, zstd» по умолчанию; для нашей
  системы решено потом заменить на файловый swap размером в половину
  оперативной памяти (простота).
- **Загрузчик** — GRUB.
- **Ядро** — linux.
- **Hostname** — `archlinux`.
- **Пользователи** — root и `user`, для тестовой VM пароли `123`; `user` с
  правами sudo (группа `wheel`). Другие группы не нужны: для X/Wayland
  в современном Arch отдельных групп не требуется (video/audio/input
  раздаются через polkit/udev). Значения — только для тестовой VM, в релиз
  не переносить.
- **Профиль** — пропускать (профили archinstall — это server/desktop/minimal;
  наш ISO приносит свой набор, там выбор дублируется).
- **Приложения и пакеты pacman** — пропускать: набор программ определяется
  нашим списком пакетов, а не вопросами установщика.
- **Сеть** — NetworkManager (как в Linux Mint — меньше проблем).
- **Часовой пояс** — UTC (Москву пока не настраивали).
- **NTP** — включить.

## Сохранённый конфиг

Файл — `install/archinstall-config.json` (валидный JSON, archinstall 4.4,
20 ключей верхнего уровня). Извлечён из `/var/log/archinstall/install.log`
установленной системы: сам файл «Save configuration» пережил только живую
среду и погиб при выключении (см. «Извлечение файлов с диска VirtualBox»).

Ограничения перед использованием в автоматизации (вариант Б):

- размеры и координаты разделов привязаны к 64-ГБ диску тестовой VM —
  под другой диск пересчитывать;
- паролей в конфиге нет (`auth_config` пуст — они вводились интерактивно);
  для безинтерактивной установки добавлять отдельно;
- пустые `packages`, `profile_config`, `services` — подтверждение, что
  установка шла без выбора программ.
