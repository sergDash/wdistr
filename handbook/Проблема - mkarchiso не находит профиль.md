# Проблема - mkarchiso: «Profile ... is missing profiledef.sh»

Статус: **решено** (2026-09-26).

## Симптом

```
[mkarchiso] ERROR: Profile '/home/user' is missing 'profiledef.sh'!
```

Профиль распакован в `/root/iso`, запуск — `cd /root/iso && sudo mkarchiso -v .`.

## Причина

`cd /root/iso` выполнен **без root**: каталог `/root` для обычного пользователя
недоступен, команда `cd` не срабатывает, shell остаётся в домашней папке.
`mkarchiso -v .` получает текущую папку (`/home/user`) и не находит в ней
`profiledef.sh`. Тот же подвох у `tar -xzf ... -C /root` — без root он
распаковывать не может.

## Решение

Не переносить профиль в `/root`. Распаковка в домашнюю папку (sudo не
нужен), сборка — с явным путём:

```sh
tar -xzf /tmp/p.tgz -C ~          # даёт ~/iso
sudo mkarchiso -v ~/iso            # tilde раскрывается ДО sudo
```

`sudo mkarchiso` обязателен: mkarchiso работает с loop-устройствами и
монтированиями. Путь указывать явно, без `.` — так ошибка исхода
(«не та текущая папка») невозможна в принципе.

## Дополнение: куда mkarchiso кладёт выходные файлы

Каталог `out` создаётся **относительно текущей папки запуска**, а не профиля:
запуск из домашней папки → ISO появится в `~/out`, а не `~/iso/out`
(проверено 2026-09-26). Каталог `out` попадает под `.gitignore` независимо
от уровня.
