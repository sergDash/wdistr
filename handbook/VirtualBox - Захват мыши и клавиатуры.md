# VirtualBox - Захват мыши и клавиатуры

## Симптом

В окне виртуальной машины «залипают» мышь и клавиатура: курсор пропадает с хоста,
клавиатура уходит в гость, а правый Ctrl (клавиша хоста) не освобождает.
Перевотыка USB-устройств не помогает.

Воспроизведено 2026-09-25: хост Linux Mint 22.3 (X11, раскладка ru,us),
VirtualBox 7.2.14, гость — загрузочный Arch ISO без Guest Additions.
Вышли командой `poweroff` внутри гостя. Корневая причина не установлена —
см. порядок диагностики ниже.

## Как устроен захват

- Захват живёт только в окне VM: это программный перехват указателя и
  клавиатуры в X-сервере хоста. Сам хост продолжает работать — просто курсор
  физически не выходит за пределы окна VM. Отсюда следует главное: команды
  управления выполняются **в терминале хоста**, снаружи VM.
- Без Guest Additions плавной интеграции нет: клик в окно VM захватывает
  мышь целиком, «автозахват клавиатуры» — клавиатуру.
- Освобождение — клавиша хоста (по умолчанию правый Ctrl). Её нажатие
  перехватывает VirtualBox на стороне хоста, минуя гость.
- Клавиша хоста хранится в `~/.config/VirtualBox/VirtualBox.xml` (элемент
  `<HostKey>`). На нашей машине его нет — значит, действует значение
  по умолчанию: правый Ctrl.
- Перевотыка USB-клавиатуры/мыши и отключение USB-поддержки VM захват
  не снимают: дело в программном перехвате, а не в устройствах (проверено
  у нас и подтверждено на форуме VirtualBox).

## Как добраться до терминала хоста, если всё захвачено

Порядок от быстрого к надёжному:

1. **Alt+Tab с клавиатуры** — переключение окон хоста, часто проходит
   в обычном оконном режиме (после нажатия клавиши хоста — тем более).
   Как только фокус ушёл из окна VM, VirtualBox снимает захват.
2. **Выключить гость изнутри** — клавиатура в госте, как правило, работает:
   `poweroff`. При полной остановке VM захват снимается всегда — по
   тикетам VirtualBox, это часто единственный способ (наш выход 2026-09-25).
3. **SSH с телефона или другого компьютера** — гарантированный путь при
   полном параличе локального ввода: подключились извне, выполнили команду
   остановки (см. ниже). Требует заранее включённого sshd на хосте —
   включить заранее, пока всё спокойно.

## Команды на хосте (VM должна быть запущена)

Гарантированный сброс — остановка VM (захват снимается вместе с процессом):

```bash
VBoxManage controlvm wdistr-build poweroff
```

Попытка сбросить «залипшую» клавишу хоста без остановки VM — эмуляция
нажатия правого Ctrl:

```bash
VBoxManage controlvm wdistr-build keyboardputscancode e0 1d e0 9d
```

Скан-коды даются шестнадцатеричными литералами **без префикса `0x`**
(с `0x` команда отвечает ошибкой `is not a hex byte`); пары `e0 1d` / `e0 9d`
— нажатие и отпускание. Статус проверки: команда принимается (проверено на
нашей VM), эффект освобождения захвата не подтверждён — проверить при
следующем случае.

## Порядок диагностики при повторении

1. Нажат именно правый Ctrl (не левый), окно VM в фокусе.
2. Проверить, что правый Ctrl вообще доходит до хоста: `xev` (если установлен)
   — при нажатии должны появиться события keysym `Control_R`.
3. Залипшая клавиша хоста: если событие отпускания потерялось (быстрое
   переключение фокуса), VirtualBox считает клавишу нажатой, и повторные
   нажатия не срабатывают. Снимается эмуляцией нажатия (команда выше);
   при неудаче — остановка VM.
4. Сторонние перехватчики ввода (USB-ресиверы, макросы, горячие клавиши
   хоста) — по данным форума VirtualBox, встречались случаи, когда они
   не давали клавише хоста сработать.
5. Зафиксировать исход в этой статье: что сработало, что оказалось причиной.

## Обходные пути сообщества (не проверяли)

- Сменить клавишу хосту на другую (настройки VirtualBox, раздел «Ввод»).
- Отключить автозахват клавиатуры: Файл → Настройки → Эксперт → Ввод →
  Auto Capture Keyboard (из опыта пользователей с зависаниями ввода).

## Следующие шаги для проекта

- Включить sshd на хосте разработки — страховка от «полного паралича» ввода.
- В сборочную VM поставить `virtualbox-guest-utils` — появится интеграция
  мыши и клавиатуры, захват станет не нужен.
- Открыто: ставить ли `virtualbox-guest-utils` в профиль нашего ISO, чтобы
  тесты в VirtualBox шли без захвата (см. открытые вопросы в `AGENTS.md`).
