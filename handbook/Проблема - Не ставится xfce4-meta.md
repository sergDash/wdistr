# Проблема - Не ставится xfce4-meta: как проверять имена пакетов

Статус: **решено** (2026-09-26).

## Симптом

При безинтерактивной установке archinstall останавливается с ошибкой:

```
target not found: xfce4-meta
```

## Причина

`xfce4-meta` — метапакет из мира Debian/Ubuntu. В Arch Linux пакета с таким
именем нет: рабочий стол XFCE собирается **группой** `xfce4` — при установке
группы pacman ставит все её пакеты (14 штук: панель, сессия, оконный менеджер,
Thunar, терминал, exo, garcon, tumbler и др.).

## Решение

В `install/archinstall-config.json` имя `xfce4-meta` заменено на группу
`xfce4`. Остальные имена списка подтверждены по базе.

## Как проверять имена пакетов заранее

С базой зеркала, с которого ставим (проверено 2026-09-26):

```bash
curl -fsSL -o extra.db.tar.gz "https://geo.mirror.pkgbuild.com/extra/os/x86_64/extra.db.tar.gz"
mkdir extradb && tar -xzf extra.db.tar.gz -C extradb
ls -d extradb/<имя-пакета>-*     # есть вывод — пакет существует
```

Участники группы — поискать `%GROUPS%` в файле `desc` нужного пакета
(или наоборот: собрать всех, у кого в `desc` есть нужная группа, — цикл по
`extradb/*/desc` с чтением строки после `%GROUPS%`).
