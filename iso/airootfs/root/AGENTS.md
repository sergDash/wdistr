# AGENTS.md — живая среда wdistr

Система запущена с установочного ISO дистрибутива wdistr (живая среда
Arch, консоль tty1, автовход от root). Этот файл — инструкция для
агента (opencode), работающего прямо здесь.

## Среда

- `opencode` — агент, `/usr/local/bin/opencode`.
- Раскладка клавиатуры — keyd: тап по **Shift** переключает us/ru
  (в консоли и в X), удержание Shift — обычный Shift; тап по Caps
  Lock — Alt+Tab.
- Сеть поднимается по DHCP автоматически; зеркала только из списка
  дистрибутива (`mirrors.txt`), чужие не добавлять.
- Конфигурация установки: `/root/wdistr/` (archinstall-config.json,
  go.sh). Команды живой среды: `setup`, `disks`.

## Правила

- `setup <имя> <пароль> <диск>` СТИРАЕТ целевой диск — запускать
  только по прямой команде пользователя.
- Перезагрузка, выключение, `pacman -Syu`, установка пакетов — только
  с подтверждения пользователя: перезагрузка обрывает текущую работу,
  pacman конфликтует с идущей установкой (конкуренция за `db.lck`
  даёт битый ISO и битую целевую).
- Разрушающие действия (запись и удаление на дисках, размонтирование
  чужих точек) — только после явного вопроса.

## Как проверить установленную систему

После `setup` целевая система размонтирована. Для проверки:

```sh
mount -o subvol=/@     /dev/sda2 /mnt
mount                  /dev/sda1 /mnt/boot
mount -o subvol=/@home /dev/sda2 /mnt/home
```

Разделы — `lsblk -b /dev/sda`, сабволюмы — `btrfs subvolume list /mnt`.

Что смотреть:

- `tail /mnt/var/log/archinstall/install.log` — в конце строка
  «Installation completed without any errors»;
- `ls -la /mnt/home/` — домашняя папка пользователя создана;
- `systemctl --root=/mnt is-enabled sshd lightdm NetworkManager` —
  службы включены; таймеры автообновления — `find
  /mnt/etc/systemd/system -name '*.timer' -path '*wants*'`;
- `pacman --root /mnt -Q <пакет>` — нужные пакеты на месте;
- fstab: UUID из `/mnt/etc/fstab` сверить с `blkid /dev/sda*`;
- размер корневого раздела = (размер диска − 1074790400), выровненный
  вниз по 1 МиБ, минус 1 МиБ запаса в конце диска;
- графика и SSH после перезагрузки: логин lightdm, вход по ключу
  `~/.ssh/wdistr_build_vm` (его публичная часть доставляется в
  `authorized_keys` при установке).

После проверок — размонтировать: `umount /mnt/home /mnt/boot /mnt`.
