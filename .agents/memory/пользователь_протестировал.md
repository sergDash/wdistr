Этот файл с замечаниями от тестирования дистрибутива.

- Главное меню программ со скругленными углами и без нашей светлой рамки.
- Если диск один, то `setup user 123` - достаточно без указания диска, а если запустить без указания и диска два, то выводить список.
- Игра Space Engineers имеет значок Стима на панели, а не свой.
- В карточку знаний что интерфейс Steam на русский переключается из настроек Steam.
- Отключить блокировщик экрана.
- Отключать монитор через 1 час.
- При нажатии кнопки питания - выключать.
